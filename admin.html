☁️ تفعيل مزامنة البيانات السحابية (Firebase)

لظهور البيانات على الجوال وجميع الأجهزة في نفس اللحظة، يجب السماح بقراءة وكتابة البيانات في قواعد أمان Firebase. اتبع هذه الخطوات السريعة:

  1. افتح موقع Firebase Console.
  2. اختر مشروعك: dev-matrix-app.
  3. من القائمة الجانبية: اختر Build ثم Firestore Database.
  4. اضغط على تبويب Rules (القواعد) في أعلى الصفحة.
  5. انسخ الكود أدناه واستبدل به القواعد الحالية، ثم اضغط Publish (نشر):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
